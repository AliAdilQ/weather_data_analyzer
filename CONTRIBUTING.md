# Contributing

1. Fork [AliAdilQ/weather_data_analyzer](https://github.com/AliAdilQ/weather_data_analyzer).
2. Create a branch: `git checkout -b feature/your-improvement`.
3. Follow the README setup steps and make focused changes. Keep business logic in services, validate forms, and protect administrator operations.
4. Run `python -m pytest -q`. For interface changes, check desktop and mobile layouts and refresh relevant screenshots.
5. Commit your changes and submit a pull request explaining the behavior, motivation, and verification.

Never include real credentials, `.env`, database files, or virtual environments. Report security issues privately to the repository owner rather than publishing sensitive details.
