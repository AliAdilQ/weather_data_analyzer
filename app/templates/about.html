From API response to useful insight

This project connects backend development, REST API integration, data analysis, data visualization, SQL database management, authentication, and responsive frontend development in one cohesive application.

Live observations come from OpenWeather. Without an API key, or when the provider is unavailable, supported cities use explicitly labeled synthetic demo data. Demo observations let you explore every feature without an external account.

Designed with separation in mind

An application factory and blueprints organize the backend. SQLAlchemy manages observations and search history, Pandas and NumPy aggregate metrics, and Chart.js brings those metrics to life. Flask-Login and CSRF-protected forms secure administrator workflows.

Know what the data means

History contains observations collected or manually entered into this application; it is not an automatic historical weather service. Dashboard charts average saved observations by UTC date. Demo data is synthetic, and city comparisons may use observations from different times.
